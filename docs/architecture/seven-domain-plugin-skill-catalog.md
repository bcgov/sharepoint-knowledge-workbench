## `sharepoint-workbench-setup`

Foundational access, connection and project/document configuration for the whole workbench: guides app-registration requests (unattended App-Only/certificate and interactive/delegated), generates the root SharePoint connection config, runs the document-workflow intake wizard, validates the SharePoint connection and written configuration/profile files, resolves document input/output paths, and provides live network-reachability, authentication and PnP effective-capability probes. Zero tenant I/O by default and zero document extraction/rendering -- live probes are opt-in scripts you run yourself.

## `sharepoint-document-conversion`

SharePoint document conversion: extracts a source .docx into a normalized source document, analyzes topic structure and chunking strategy, assembles a validated canonical content package, renders it to multipage Markdown or SharePoint modern pages through local rendering templates, validates the rendered output, and provides single-topic editorial review of rendered Markdown or published pages. Every workflow is local or read-only; nothing in this package writes to a tenant.

## `sharepoint-site-assessment`

Read-only assessment of classic and modern SharePoint sites: analyzes exported inventories and schemas offline (per-page migration complexity scoring, web-part behavior grouping, site navigation depth, custom-form classification, permissions and broken inheritance, schema export comparison, choice columns, calculated columns) and collects them live with read-only PnP.PowerShell/on-prem collectors for lists, libraries, content types and pages. Analysis rules and behavioral knowledge are caller-supplied, never built in; no workflow writes to a tenant. Includes recursive CSV file inventories across all libraries and subsites on Online or on-prem, with interactive authentication and explicit partial-result reporting.

## `sharepoint-site-build-and-publish`

Every writing script is dry-run by default, gated behind -Execute plus an operation-specific -ConfirmToken. Includes inventory-driven bulk static page/document downloads with a source-to-local CSV manifest for offline Python link analysis.

## `sharepoint-site-migration`

Plans and executes SharePoint site migration: validates a source-site export, derives the object dependency graph and migration wave plan, scaffolds wave scripts, analyzes and modernizes classic pages (plan, preview, single and library conversion, validation, reports), migrates list content with two-pass lookup re-linking, and extracts and updates links in pages, documents and rich-text columns. Planning and analysis are read-only; most writing scripts are dry-run by default, gated behind -Execute plus an operation-specific -ConfirmToken; the preserved consumer-specific repair script in the content-audit folder is a documented exception (it writes unless -DryRun is passed), so check each script's own parameters. Includes offline Python CSV link inventories, explicit per-run source-to-target mapping, deterministic link-rewrite planning, and a read-only Online stored-page-content collector; these are local/read-only plans, not SharePoint writes.
