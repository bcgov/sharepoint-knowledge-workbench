# Start Here

This repository contains installable plugins for SharePoint workbench setup,
document conversion, site assessment, site build and publishing, site
migration, Copilot agents and native skills, and SPFx development.

## Project map

- [Architecture](architecture.md) describes the repository and plugin model.
- [Installation guide](INSTALL.md) explains how to install and bootstrap the plugins.
- [Use-case index](docs/use-cases/README.md) describes the work each capability supports.
- [Research index](docs/research/README.md) collects research and field notes.
- [Seven-plugin catalog](docs/architecture/seven-domain-plugin-skill-catalog.md) lists the proposed plugin and skill organization.

Start with the architecture and installation guide when setting up the workbench;
use the relevant plugin skill for a specific SharePoint task.
