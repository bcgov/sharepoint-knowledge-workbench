# Start Here

This repository contains the unified **SharePoint Knowledge Workbench** (`@sharepoint/sharepoint-workbench`), a comprehensive suite of 11 domain skills and 9 specialized subagents for SharePoint setup, site assessment, document conversion, schema management, lists/libraries, navigation sync, page publishing, modernization, site migration, SPFx development, and Copilot agents.

## Project Map

- [Architecture Overview](architecture.md) describes the single-plugin architecture, 11 domain skills, and 9 subagents.
- [Installation Guide](INSTALL.md) explains how to install the workbench via APM or marketplace.
- [Use-Case Index](docs/use-cases/README.md) describes the work each capability supports.
- [Master Migration Inventory](docs/plans/master_migration_inventory.csv) tracks the full 108-to-11 consolidation mapping.
- [Consumer Migration Plan](docs/plans/csb_intranet_sp_migration_refactor_plan.md) details how downstream repositories adopt the consolidated plugin.

Start with the architecture and installation guide when setting up the workbench; use the relevant domain skill mode for specific SharePoint engineering tasks.
