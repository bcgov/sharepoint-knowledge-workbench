# sharepoint-provisioning

Real PnP.PowerShell tenant-write executors for site columns, list columns, content types, views, items, libraries, sites, branding, navigation, permissions, and taxonomy.

## Overview

This plugin provides the real tenant-facing PowerShell execution layer that applies declarative provisioning plans generated by `sharepoint-schema-reconciliation` or custom migration plans.

### Safety Architecture

- **Dry-run by default**: Every executor outputs a complete preview of the planned actions and parameters without modifying tenant state.
- **Explicit Write Gating**: Real execution requires passing `-Execute` alongside an operation-specific `-ConfirmToken` matching the plan.
- **Connection Resolution**: Reusable connection helper `Get-WorkbenchConnectionConfig.ps1` resolves interactive OAuth2 or client credentials from `config.psd1`.

## Skills Included

1. **`sharepoint-apply-provisioning-plan`**: Executes full provisioning plans (`New-PnPList`, `Set-PnPList`, `Add-PnPContentType`, `Add-PnPField`, etc.) against a live SharePoint Online site.
