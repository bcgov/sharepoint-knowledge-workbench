CEIS ACCESS LEVELS

Users are assigned access roles in CEIS for each level and class of files. These access roles determine the files they can access in CEIS, and whether or not they can perform various data entry functions.

Once a user has access to a particular registry location, they will have the same access to the files of all associated circuit courts for that location. Also, if the user's home location is the receiving location for a location that has been closed, the user will have the same access to the files of the closed location. (For example, Nanaimo is the receiving location for Parksville, so Nanaimo users will have the same access to Parksville files as they have to their own registry files.)

The access roles are:

  • No access (to selected classes)

  • Read Only access (to selected classes)

  • Full Update access (to selected classes, other than the calendar)

  • System Administrator access

  • Maintain Calendar access only

  • Sheriff access

Please speak with your manager or supervisor if your access role needs to be changed.

User Role (Type)

In some regards, access is affected by the user role, as well as the access role. For example, only users assigned the user role of "Court Clerk" are able to record results in the In-Court Module, if they have the required access role of "Full Update"; a user assigned the user role of "Clerk/Recorder" will not be able to record appearance results in the In-Court Module, even though the user still has the required access role of "Full Update".

Sheriff Access

A user role (type) of "Sheriff" allows Sheriff Services personnel to create/edit/modify/delete sheriff comments only, even for transferred-in files. The Sheriff access role is "Read Only", which applies to all other aspects of the application.

Extended Access

Users with extended access can update file details in CEIS for files transferred for appearance purposes, whereas users with "Full Update" access can only update the appearance results on transferred files.

Only a limited amount of experiences CEIS Users per site are provided with extended access.

It is the responsibility of the site contacts to advise the AG CEIS Support Group of the users at their location who should have access to the files of all court locations in the province.
