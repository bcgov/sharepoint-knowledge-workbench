ORDERS

It is important to understand the following concepts:

  • All known orders for a civil file must be entered in CEIS.

  • Typically, when an order is made as a result of a court hearing, only the order type, date granted, terms of order, POR/CFC tracking, and adjudicator is entered. When the order is filed at the registry or produced and signed, the order details are updated with the date entered, and any further information.

  • Protection Orders are ALWAYS stand alone orders.

There are three methods of entering orders:

  • via the Orders module of Maintain File — click Orders from the left-hand sidebar menu.

  • via the Documents module of Maintain File — click the ADD ORDER button in the main Documents screen.

  • via the Record Results module — click the ADD ORDER button in the Record Document and Issue Results screen.

Regardless of which method you choose to access the Orders screen, once in the Orders screen, the procedure for entering an order is identical.

The Orders screen consists of five tabs:

  • Order Details: This screen lists all orders (if any) that have been entered against the file. From this screen you can add a new order or edit an existing one. This is where you enter or edit the details of the order. Once you click SAVE the Order Terms screen will appear.

  • Order Terms: In this screen you will enter the terms of the order in conformance with our best practices.

  • POR/CFC: If an order is to be sent to the Protection Order Registry (POR) or the Canadian Firearms Centre (CFC), additional information needs to be entered in this screen. This tab will only be activated if the Protection Order or Firearms Order boxes are selected in the Order Details screen.

  • Referral Tracking: This screen tracks referrals against a selected order on the file. (An order may have zero to many referrals during the life of the file.)

  • Seal Order Details: This screen is used when a Judge makes an order sealing documents or a file. The tab will be activated after the Seal Order box is selected.

Order Details

The Order Details screen is where you enter or update information about the order such as order type/description, date granted, and adjudicator name.

To edit/update an existing order, highlight the one you wish to edit/update in the Order Details screen and double-click. The details of the order will then populate the fields below; from here you can edit information as required.

To add a new order, click the Add Order tab; you'll be taken automatically to the first field to be populated in the lower portion of the screen, which is Document Access. This field will automatically populate from the file details. The fields which are mandatory will have an asterisk (*) beside them.

Document Access (1): This specifies the access restrictions on the order.

Order Type (2): The type of order. (Select one from the drop-down list.)

Date Submitted (3): This is the date the order was submitted to the court.

Date Granted (4): The date the order was granted by a Judge, Associate Judge, or Registrar (in the courtroom). In the case of a "not spoken to" order, this is the date the order was signed by the court.

Date Entered (5): This is the date the order was entered by the registry. When this date is entered, CEIS will assign the next sequential document number for that file to the order. (For example, if there are 10 existing documents for the file, this new order would be document sequence number 11.)

Varied Date (6): The date the order was varied.

Volume Prefix (7): This is the alpha character of the volume in which the original order is filed. The volume refers to a binder, or "Shannon file", that is located in the registry. (This is used in only a limited number of registries.)

Folio (8): This is the number of the folio within the volume in which the original order is filed. (This is used in all registries.)

Amended Doc Seq # (9): If you are amending a previous order, this number is the original document sequence number.

Statutory Filing Fee (10): If e-filed and there is a statutory filing fee the amount will be shown here. This is not a fillable field in CEIS.

Adjudicator (11): The name of the Judge, Associate Judge, or Registrar that issued the order. In the case of a "not spoken to" order, leave this field blank.

Cancelled Date (12): If the order is cancelled, enter the cancellation date here.

Ended Date (13): The date the order was ended.

Volume (14): This is the numerical portion of the volume in which the original order is filed. The volume refers to a binder, or "Shannon file", that is located in the registry. (This is used in all registries.)

Made (15): This is Order Made Types, you can choose which is appropriate in the drop down menu.

Duration (16): Here you can select whether the Order is a Final or Interim Order.

Scan (17): If an image is scanned into CEIS, there will be a tick in this box.

From CSO (18): If the order was e-filed, there will be a tick in this box.

Seal Order (19): If a Sealing Order is made, tick this box and it will open up the Seal Order Tab. Then review How to Seal a File for data entry details.

Protection Order (20): Check this box if the order is a Protection Order. This flag is used as an indicator for tracking and processing. Even if you set this flag in CEIS, you're still required to forward the order to the Protection Order Registry.

Firearms Order (21): Check this box if the order is to be forwarded to the Canadian Firearms Centre. Note that even if you set this flag in CEIS, you're still required to forward the order to the Central Registry.

Produce Form (22): When ready to produce an Order click here to begin the process. (Registry is obligated to produce an order for self-represented litigants in Provincial Court, or otherwise directed by a Judge)

Print terms of Order (23): Used to produce the Terms of an Order to be provided to for a party, counsel or Judge.

CFC Details (24): If a CFC Order is granted, this button will become available.

Duplex (25): Check this box if a paper document is printed back to back, and it needs to be scanned into CEIS.

View Doc. (26): Used to view an image that is already scanned or uploaded into CEIS.

Load Doc. (27): Used when upload loading a PDF image from your computer into CEIS.

Scan Document (28): When you are ready to scan a paper filed document, click this button.

Judicial Action (29): This is for tracking and storing Judicial Action within CEIS.

Delete (30): Highlight the Order with the blue line, then click this button if an entry needs to be deleted.

Save (31): When editing is complete, click save.

Reset (32): Use if the entry needs to be reset, will only function prior to clicking save.

Order Terms

The Terms of Order field is where you will enter the terms of the order granted.

Orders granted in Court, the Order terms will pull from CCD into CEIS.

When entering the Order Term manually, there are 2 options:

  • Enter the terms free form, or

  • Select one of the Common Terms (Picklist items) in the drop down menu.

Order Filed by Counsel

Counsel will sometimes request a copy of the Court Summary Sheet to review when they are drafting Court Orders.

To locate the Court Summary Sheet to provide to counsel go to Appearance 🡪 click on the specific appearance 🡪 Record Results 🡪 Appearance 🡪 Print Court Summary Sheet:

Orders that are granted and filed by Counsel are checked by a clerk/DDR and then signed by a Judge or DDR.

When an Order is received it is best practice to track the Order.

Date Referral (1): This is the date the referral is made.

Court List (2): The type of list.

Reason (3): Reason for the referral.

Assigned to (4): Who the Order is referred to.

File Attached (5): If the file is being sent together with the Order.

Date Rejected (6): Rejected Date if the Order needed corrections.

Date Signed (7): Date if the Order was approved and signed.

Referral Comment (8): If there are any comments for this Order, type them here.

Delete Referral (9): Double click on the referral and click this button to delete.

Save (10): To save the referral.

Reset (11): To re-set the content entered.

If a new Referral needs to be added click the “Add Referral” Button.

NOTE - If the Order is inconsistent with the Court Summary Sheet and corrections need to be made create the Registry Rejection Letter – Administrative (CEIS Code RRLT) and attach the original order back to the party/counsel.

Make a copy of the letter and the order and place it in the file.

Once an Order is signed by the DDR/Judge:

  1. The Order is returned to the Registry Clerk for further data entry.

  2. The Order is stamped (Provincial) or sealed (Supreme).

  3. The referral is updated and the signed date is filled in.

  1. The “Date entered” is data captures based on the date of the stamp/seal

  1. The Order is scanned into CEIS against the already entered Order.

Or if provided in a PDF document via email, you may Load the Document by clicking here, after you have saved the PDF to your computer.

Order Production

Judges sometimes order the Registry to Produce Orders, or in Provincial Family, if neither party has counsel, it is the Registry’s responsibility to Produce Orders.

Here’s How:

  1. Proof read the terms of the Orders entered to ensure:

    1. Names are in full and spelled correctly,

    2. Proper punctuation and grammar is used,

    3. Date of birth(s) are entered (if required),

    4. Monetary amounts are correct, and

    5. Protection Order terms and Order-General terms are not combined on one Order.

  2. Once all relevant information on this screen are completed, press Produce Form

  4. If you notice there is an AKA against the Party, we need to deselect the AKA here so it does not appear on the Style of Cause:

Court Location (1): Location of the file.

Court Appr. Address (2): Location where the appearance was heard.

Clerks initials (3): The clerk who is signing off on the Order

Judge Name (4): The Presiding Judge’s name

Court attendance (5): Information is pulled from the appearance information, this is a fillable and editable field.
