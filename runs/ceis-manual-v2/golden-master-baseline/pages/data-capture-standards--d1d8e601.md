## DATA CAPTURE STANDARDS 

The Civil Electronic Information system (CEIS) was implemented as the civil provincial case tracking system in 2004.

With the addition of our electronic initiatives, e-filing, e-registry, Court Services Online, and the integrated court vision, it is imperative to set formal data capture standards and consistently maintain these standards at each court location across the province. These enhanced standards have been approved by the executive and senior district and local managers support the change process to transition to these standards.

The following timelines and content are mandatory CEIS standards as of September 1st, 2007:



### Data Capture Requirements

*All documents are mandatory*

- Each document filed per court file must be entered in CEIS.

*All documents entered within 24 hours*

NOTE - 24 hours refers to elapsed clock hours versus business hours

*All results from court entered the same business day*

NOTE - 24 hours refers to elapsed clock hours versus business hours



### Data Element Requirements

Filing party

- The filing party must be entered on the Parties Filed by tab in the Documents module for each document entered into CEIS.

Date filed

- Each document filed through Supreme Court Scheduling must be entered in CEIS with the date that appears on the SCSS stamp. Do not re-stamp these documents with the registry stamp.

Enter issues for all documents

- Each document that contains an issue must have that issue entered. Issues must be entered at the time the document is entered, whether the document is scheduled for a court appearance or not.

- To assist registry staff in selecting the correct issue code, the issue table displays only issues that apply to the level and class of the current file.

Enter court dates received from trial division before appearance date

- Each document from Supreme Court Trial Scheduling with a court date must be entered prior to the appearance date. This includes both the document and court date.

Enter Act per initiating document

- When a matter is commenced pursuant to a specific Act, that Act, when known, must be entered in the Act field on the Document Details screen. The Act must be entered against the initiating document for all levels and classes of files.

Use of code \'Other\'

- Not all court hearings or appearances fall under a pre-existing document or issue code. The code \'Other\' is to be entered where there are existing applicable document and issue codes. In the event the appropriate document or issue code does not exist, notify the [AG CEIS Support](mailto:Courts.Ceis@gov.bc.ca) so the code can be added.

Claim value

- For all Small Claims matters the value of the claim and counterclaim must be entered in CEIS. Whenever a claim value is provided on Supreme Court initiating documents, the value must be entered in CEIS.

Scheduling multiple documents

Where there is one appearance for multiple documents, ensure that all documents are scheduled together against that appearance. Do not schedule a separate appearance for each document unless the appearance reason differs. For example: for a Small Claims settlement conference, ensure that the Notice of Claim and Reply with Counterclaim are scheduled together, not individually.
